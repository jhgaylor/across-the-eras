# across-the-eras 📺

Rewatch guides for the shows you keep going back to — one app, many shows. Live at https://eras.inevitable.fyi

Every show gets an interactive **era chart** (showrunners, arcs, big bads, rosters, real-world events…) sitting on
top of every episode; every bar on the chart is a filter. Plus vibes, guest-character filters, full-text search,
watched tracking, 🎲 Surprise me, shareable filter URLs, and a mobile filter drawer.

Successor to the single-show sites [moose-and-squirrel](https://github.com/jhgaylor/moose-and-squirrel) (Supernatural),
[goat-gideon](https://github.com/jhgaylor/goat-gideon) (Criminal Minds) and [greater-fool](https://github.com/jhgaylor/greater-fool)
(The Newsroom), which are imported here unchanged.

## Layout
```
index.html, app.js, styles.css     the shell: landing page at /, explorer at /<slug>/
shows/<slug>/show.json             branding + metadata          ┐
shows/<slug>/episodes.json         TVmaze episodes              │ one self-contained
shows/<slug>/cast.json             TVmaze guest cast            │ package per show
shows/<slug>/eras.js               the chart (ERAS/ERA_CATS/…)  │
shows/<slug>/tags.js               curated vibes                ┘
shows/index.json                   generated by scripts/build-index.py — the landing page reads it
```

## Run locally
```
python3 scripts/dev-server.py 8770     # SPA fallback so /<slug>/ works; then open http://localhost:8770
```

## Add a show
Read [CONTRACT.md](CONTRACT.md). In short: create `shows/<slug>/` with the five files above (copy the scripts and
formats from an existing show), run `python3 scripts/build-index.py`, commit. CI fails if `shows/index.json` is stale.

## Deploy
`ghcr.io/jhgaylor/across-the-eras` (nginx :8080, `/healthz`, `try_files … /index.html`), built by
`.github/workflows/build.yml` on push to `main`, which pins the new `sha-*` tag into `k8s/deployment.yaml`;
home-cloud's Flux reconciles `k8s/` to `eras.inevitable.fyi`.

## Analytics
One PostHog project (`eras.inevitable.fyi (all shows)`, US). Every event carries a `show` super-property
(`landing` on the picker). Autocapture is off; explicit events: `show_selected`, `era_selected`, `season_selected`,
`vibe_selected`, `character_selected`, `searched`, `sort_changed`, `filters_reset`, `surprise_me`, `episode_opened`,
`watched_toggled`, `chart_toggled`, `filters_drawer_opened`.
